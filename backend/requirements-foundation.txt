# Foundation forecasters: OPTIONAL extras, exploratory only.
#
# Not part of the core install, on purpose. A fresh clone following the README setup does not
# need this file, and nothing here is required for the app, the registry or the test suite to
# work. Every import in backend/foundation_models.py is lazy, so with these absent the models
# report themselves as not installed and everything else behaves normally.
#
#   ./backend/.venv/bin/python -m pip install -r backend/requirements-foundation.txt
#
# WHY EVERY VERSION IS EXACT
# --------------------------
# A zero-shot forecast is reproducible only if both the code and the weights are fixed. The
# versions below are the ones actually installed and actually measured on 2026-08-19, not a
# compatible range. The weights are pinned separately, by commit hash, in
# backend/foundation_models.py -- a tag or `main` can move, and a forecast whose weights can
# change underneath it is not a record of anything.
#
# INSTALLED INTO backend/.venv, AND WHY THAT WAS SAFE
# ---------------------------------------------------
# `pip install --dry-run` was run first and checked against the committed snapshot at
# docs/sessions/pip-freeze-before-fm-2026-08-19.txt. It would not move numpy (2.4.4), pandas
# (3.0.2) or torch (2.11.0), which are the three that would have forced a separate interpreter.
# Verified after installing: all three unchanged, along with scikit-learn, lightgbm, xgboost,
# catboost and statsmodels.
#
# One package was upgraded in place rather than added: click 8.3.1 -> 8.4.2, required by typer,
# which transformers pulls in. That is the only pre-existing package this file changes.
#
# WHAT DOWNLOADS, AND WHEN
# ------------------------
# Installing these fetches no model weights. Weights arrive the first time a model is actually
# run and are cached under ~/.cache/huggingface/hub. After that first fetch nothing downloads at
# runtime: the pinned revision resolves from the local cache without a network call. Measured on
# the Chronos small bolt checkpoint: 17.4s on the first load including download, 0.1s from cache.
